FAQ

Questions, answered

Can't find what you're after? Reach out and we'll answer directly.

Q1What's the usual turnaround time?

Most short-form edits land within 48 hours of receiving footage. Long-form projects and heavier motion graphics work typically run 5–10 days depending on scope — we'll always confirm a timeline before starting.

Q2How many rounds of revisions are included?

Every project includes two rounds of revisions as standard. Additional rounds can be added if a project needs more back-and-forth — just flag it up front so we can scope it properly.

Q3What footage formats do you accept?

Pretty much anything — raw camera files, phone footage, screen recordings, or existing project files. If you're not sure your files will work, send a sample and we'll confirm before the clock starts.

Q4Do you work on a per-project or retainer basis?

Both. One-off projects are quoted per deliverable, while ongoing content needs (weekly cutdowns, recurring channels) run on a monthly retainer with a set number of edits included.

Q5How do we communicate during the edit?

Whatever's easiest for you — email, WhatsApp, or a shared drive folder work fine. Drafts come back as shareable links with timestamped notes so feedback stays specific and easy to track.

Q6Can you handle both short-form and long-form in one project?

Yes — a lot of clients send one long-form shoot and have us cut both the full edit and a batch of vertical/square recuts from the same footage, which keeps everything consistent and saves on cost.
